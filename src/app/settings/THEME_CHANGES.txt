SETTINGS PAGE CHANGES
=====================

1) Remove local ThemeMode type from settings.page.ts.

2) Add import:

import { ThemeMode, ThemeService } from '../core/theme.service';

3) Change theme signal initialization:

readonly theme = signal<ThemeMode>('system');

4) Add constructor:

constructor(
  private readonly themeService: ThemeService
) {
  this.theme.set(this.themeService.mode());
}

5) Replace setTheme() with:

setTheme(theme: ThemeMode): void {
  this.theme.set(theme);
  this.themeService.setTheme(theme);
}

6) Inside resetSettings(), after:

this.theme.set('system');

add:

this.themeService.resetTheme();

Your existing HTML buttons can continue calling setTheme('light'), setTheme('dark'), setTheme('system').
